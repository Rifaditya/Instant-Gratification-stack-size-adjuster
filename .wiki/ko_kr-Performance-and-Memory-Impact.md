# 성능 및 메모리 영향

## 개요

Stack Size Adjuster는 추가적인 메모리 오버헤드나 NBT 데이터 낭비 없이 극대화된 효율성을 자랑합니다.

---

## ⚡ 주요 성능 최적화

1. **원시값 보관**: 적용 한도는 `StackSizeManager` 내부의 `volatile int` 원시 변수에 보관되어 $O(1)$의 락 없는 빠른 읽기 속도를 제공합니다.
2. **NBT 팽창 제로**: 별도 NBT 태그를 주입하는 대신 바닐라 컴포넌트 코덱(`DataComponents.MAX_STACK_SIZE` 및 `ExtraCodecs.intRange`)을 직접 수정하므로 월드 저장 크기가 바닐라와 완전히 동일합니다.
3. **틱 리스너 부재**: 주기적인 틱 루프(`EndTick`, `WorldTick`)에 어떠한 로직도 실행하지 않습니다.
4. **스레드 안전한 재정의 목록**: 외부 애드온의 재정의 함수는 `CopyOnWriteArrayList`로 안전하게 순회됩니다.
