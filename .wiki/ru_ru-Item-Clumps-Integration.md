# Интеграция с Item Clumps

## Обзор

Stack Size Adjuster работает в непосредственной синергии с модом **Item Clumps** (`item_clumps >=1.0.18+26.2`). Пока Stack Size Adjuster управляет лимитами стаков в инвентарях и при выпадении, Item Clumps объединяет лежащие на земле сущности.

---

## 🤝 Схема взаимодействия

```
[ Разрушение контейнера ]
            |
            v
[ Stack Size Adjuster: InventoryDropHelper ]
Разбивает стак на ограниченное число сущностей (до 8 на слот)
            |
            v
[ Появление предметов на земле ]
            |
            v
[ Мод Item Clumps: Объединение сущностей на земле ]
Сканирует радиус в 3.5 блока и сливает предметы в одну сущность
            |
            v
[ Единая сущность с огромным числом предметов ] (Без лагов!)
```

---

## 📊 Матрица синергии функций

| Сфера ответственности | Модуль | Результат |
| :--- | :--- | :--- |
| **Лимиты стаков в инвентаре** | **Stack Size Adjuster** | Пользовательские лимиты 64/16/1 в сундуках и у игроков |
| **Спавн при поломке контейнера** | **Stack Size Adjuster** | Предотвращает появление тысяч предметов сразу |
| **Слияние предметов на земле** | **Item Clumps** | Объединяет предметы в радиусе в единые стаки |
| **Подбор предметов** | **Ядро Minecraft и Mixins** | Подбирает объединенные стаки прямо в расширенные слоты |

---

## ⚙️ Рекомендуемые настройки

При совместном использовании с **Item Clumps** установите `max_drop_entities` на **8** (или на **1** для максимальной производительности):
```text
/gamerule stack-size-adjuster:max_drop_entities 8
```
Это создает визуальный эффект рассеивания из 8 кучек, которые Item Clumps мгновенно собирает воедино.
