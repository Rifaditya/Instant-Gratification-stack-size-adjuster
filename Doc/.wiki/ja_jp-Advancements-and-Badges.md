# 進捗とバッジ

## 概要

Stack Size Adjuster はバニラの進捗システムに準拠しており、独自のカスタム進捗ツリーは導入しません。

---

## 🎖️ バニラとの整合性

* **アイテム取得条件**: 大量のスタックを拾った場合でも、バニラの進捗条件（例: `minecraft:inventory_changed`）が正常に機能します。
* **クラフト・精錬**: 拡張されたスタックをクラフト・精錬しても、レシピ解放や進捗は阻害されません。

---

## 🛠️ 統合バッジ一覧

| バッジ | 状態 | 説明 |
| :--- | :--- | :--- |
| **ModMenu 統合** | 有効 | リフレクションによる設定画面登録 |
| **YACL v3 画面** | 有効 | スライダー、数値入力、オーバーフロー警告 |
| **DasikLibrary** | 有効 | 動的ゲームルールカテゴリの提供 |
