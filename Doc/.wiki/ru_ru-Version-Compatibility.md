## 🛡️ Границы зависимостей и правила

В соответствии с правилом **1 Jar 1 Version**, зависимости в `fabric.mod.json` используют открытые нижние границы:

```json
"depends": {
    "fabricloader": ">=0.19.1",
    "minecraft": "${minecraft_dependency}",
    "java": ">=25",
    "fabric-api": "*",
    "dasik-library": "*",
    "item_clumps": ">=1.0.18+26.2"
}
```

### Правила версионирования:
1. **Никаких устаревших схем**: Для версий линейки Minecraft 26.x не используются старые номера версий `1.21.x`.
2. **Открытые нижние границы**: `minecraft >=26.2-` обеспечивает совместимость с патчами без привязки к пре-релизам.
3. **Проверка classpath**: При старте вызывается `ModVersionGuard.checkClass` с загрузчиком контекстного потока.
